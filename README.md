# PDG Portfolio Update 2026 Q3

A workbook app for the Predictable Dividend Growth portfolio. It opens in a browser and works like a spreadsheet.

Open: https://mach1rcode.github.io/PDG/

- Three sheets: Final Portfolio, Historical Data, and Sources & Checks.
- Prices and data are as of November 5, 2026.
- You can edit the cells. One button resets the workbook to the original values.
- One button prints the report as a PDF.

## Add to an iPhone Home Screen

1. Open the link above in Safari.
2. Tap Share, then "Add to Home Screen".

The app is one file, `index.html`. It needs no build step.
